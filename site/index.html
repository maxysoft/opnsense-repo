An OPNsense plugin repository

Add it once as root, then install and update these plugins from System → Firmware → Plugins, the same way as any official one.

Run as root on the firewall 
# fetch -o /usr/local/etc/pkg/repos/mxy-opnsense-repo.conf https://maxysoft.github.io/opnsense-repo/mxy-opnsense-repo.conf
# pkg update

What is in it

One package today. The repository is built from source on every change.

os-devicemonitor

Tracks devices appearing on your LAN and VLAN interfaces and alerts on new ones by e-mail or webhook. Adds a settings page, a device list and a Lobby dashboard widget.

Written by Hacesoft

Supported releases

A separate package is built per OPNsense series, because each one sits on a different FreeBSD major. Your firewall picks the right one on its own.

26.7
FreeBSD:15:amd64
Built on FreeBSD 15
26.1
FreeBSD:14:amd64
Built on FreeBSD 14

Managing it

See what the repository offers

pkg search -g -r mxy-opnsense-repo \*

See what you installed from it

pkg query -a '%R %n-%v' | grep mxy-opnsense-repo

Remove the repository

Packages you already installed stay where they are.

rm /usr/local/etc/pkg/repos/mxy-opnsense-repo.conf
