maxysoft OPNsense repository

Add the repository on your firewall, then install from System → Firmware → Plugins:

fetch -o /usr/local/etc/pkg/repos/mxy-opnsense-repo.conf https://maxysoft.github.io/opnsense-repo/mxy-opnsense-repo.conf
pkg update

What is in here:

pkg search -g -r maxysoft \*

Remove the repository (installed packages stay):

rm /usr/local/etc/pkg/repos/mxy-opnsense-repo.conf

Source: github.com/maxysoft/opnsense-repo
